# Снимки результатов

Эти файлы фиксируют данные, доступные в рабочей сессии 2026-09-07.
Дата относится к записи результатов; в серверных консольных фрагментах
временные метки отсутствовали.

- [particle_progress_2026-09-07.json](particle_progress_2026-09-07.json):
  параметры экспериментов, все 11 присланных VAL-точек большой сети до
  шага 11 000, крупные TRAIN-пики из присланных фрагментов, четыре проверки
  replay-дообучения и 16 серверных `target_std`.
- [local_phi35_c1000_audit.md](local_phi35_c1000_audit.md): читаемая сводка
  полного локального аудита одного прогона.
- [local_phi35_c1000_audit.json](local_phi35_c1000_audit.json): точные
  счётчики и статистики этого аудита по величинам и переходам.
- [Таблицы локального аудита](local_phi35_c1000_audit): все четыре CSV
  исходного отчёта — масштабы, кадры, крайние переходы и недопустимые значения.
- [local_neighbor_benchmark_2026-09-07.json](local_neighbor_benchmark_2026-09-07.json):
  замеры старого и нового точного поиска на трёх полных местных кадрах,
  с проверкой всех ID/масок. Это время поиска на CPU, не тест качества
  обученной модели и не замер полного rollout на T4.

Серверный JSON переписан из сообщений пользователя: он не заменяет исходные
`metrics.jsonl`, `train.log` и checkpoint. Обучение на 50 000 шагов по этим
данным не подтверждено как завершённое: последний доступный результат — шаг 11 000.

Для локального аудита масштабы переписаны из вывода сервера; оригинальный
серверный `stats.npz` не скачивался. Проверен только `phi35_c1000`, не все
25 прогонов. Сырые NPY и веса остаются за пределами Git. Новые измерения
нужно добавлять отдельными снимками с источником и областью проверки.
